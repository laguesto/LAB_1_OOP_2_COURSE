# Діаграма класів

Графічна версія діаграми знаходиться у файлах `class-diagram.png` та `class-diagram.svg`.

Основний зв’язок: `Person` — абстрактний базовий клас для `Student`, `Painter` та `Farmer`. `FileManager` працює з масивом `Person[]` і відповідає за збереження, читання, пошук та видалення даних.
